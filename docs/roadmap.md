### 進め方の基本（CLAUDE.md の標準フロー）
pm（仕様・タスク化） → fx-expert / data-analyst（ルール・指標の定義） → designer（画面設計） → engineer / sheets-integrator（実装） → reviewer + ux-tester（検証） → engineer（修正）

### 表の見方
- **目安規模**：`S`＝1〜1.5時間程度 / `M`＝2〜3時間程度 / `L`＝半日（4時間程度）。半日を超えそうなら着手前に分割する
- **依存関係**：そのタスクを始める前に終わっている必要があるタスク。「（先行可）」は推奨案を前提に先に着手してよいもの
- **状態**：未着手 / 進行中 / 完了 / 保留
