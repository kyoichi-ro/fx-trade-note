### U-01（中）初回のロット欄の灰色の見本「0.1 lot」が、入力済みの値に見える
- 画面・操作：S-02 エントリー（初めて記録するとき・その口座で初めてのとき）。本番 → USD/JPY → ▲買い → 価格 151.234 → ［本番で保存］
- 何が起きるか：ロット欄に灰色で「0.1 lot」と出ているので、前回値（入力済み）だと思ってそのまま保存を押すと「⚠ ロットを入力してください」で止まる。エラー後はロット欄に自動でフォーカスが移るので直すのは早いが、初めての記録でいきなり赤字のエラーが出て、30秒の目標に対して1手（約3秒）余計にかかる。入力済みの値（黒）と見本（灰）の差は、トレード直後の焦った状態・屋外の明るい画面では見分けにくい。2回目からは前回値が本当に入るので起きない（デモで初めて記録するときにもう一度起きる）。（スクリーンショット：03-entry-err-light.png / -dark.png）
- 改善案：(1) その口座で初めてのときの見本を数字にしない（例：見本を「必須」や空にする。または「例 0.1」）。(2) あるいは初回だけ 0.1 を実際の値として入れておく（前回値と同じ扱い）。(2) の方が30秒記録には効く。

### U-02（中）1lot の通貨数（初期値 1万通貨）を一度も目にしないまま記録・決済が進み、損益（円）が業者の表示と1桁ずれうる
- 画面・操作：初回起動 → エントリー → 決済。設定画面を開かずに使い始めた場合
- 何が起きるか：0.1lot・＋25.3 pips の決済が「＋253円」と表示された（1lot＝1万通貨で計算）。1lot＝10万通貨の業者を使っている人は、業者アプリでは＋2,530円なのに、アプリでは＋253円と出る。初回起動・エントリー・決済のどの画面にも「1lot＝何通貨で計算しているか」が出ないので、ずれの原因に気づけない（詳細画面の「数量 1,000通貨（1lot＝10,000）」と、編集画面の「1lotの通貨数 10,000通貨（記録したときの設定値です）」で初めて分かる）。しかも記録ごとに当時の 1lot の値をコピーする仕様（requirements 6.1）のため、あとで設定を直しても**それまでの記録の損益は直らない**（編集で口座区分を一度切り替えて戻す、という分かりにくい操作でしか取り直せない）。最初の数件を記録してから気づくと、その分の集計がずっと合わない。
- 改善案：(1) 記録0件の一覧の空状態の説明、または最初のエントリー画面のロット行の下に「1lot＝1万通貨で計算します（設定で変更）」の1行を出す（記録が1件でもあれば出さない）。(2) 決済画面の損益の下の注記「自動計算はスワップ・手数料を含みません。」に「1lot＝1万通貨」を足す。(3) 設定で 1lot の通貨数を変えたとき、保有中の記録だけでも新しい値で取り直すかを選べるようにする（T-33 で pm・fx-expert と要相談）。

### U-11（低・要実機確認）日時の欄が Chromium では「10/17/2026, 12:4」のように分が欠けて表示される

### U-14（低）画像のサムネイルの「×」の押せる範囲が、サムネイル本体と隣のサムネイルに重なっている

## 良かった点

- **決済が速くて気持ちいい**：一覧の［決済］1タップで決済価格にカーソルが入り、打つたびに「＋253円／＋25.3 pips」が大きな色付き文字で変わる。保存すると「決済を保存しました ＋253円」と金額まで出るので、業者アプリの数字とその場で見比べられる
- **前回値と口座の見分け**：2件目以降は「売買方向を選んで価格を打って保存」の5タップで済む。本番は黒（ダークでは白）の塗り、デモは琥珀、入力画面の上端の線、保存ボタンの「本番で保存」で、どちらの口座に入れようとしているかを3か所で確かめられる
- **入力ミスへの案内が親切**：「ロットを入力してください」のあと自動でロット欄に移る。「価格は小数第5位までで入力してください」「EUR/AUD の価格としては大きく外れています。通貨ペアと桁を確認してください。」のように、何をどう直すかが具体的。1lot の欄に「100,000」と入れると「カンマなしで入力してください（例：10000）」
- **データの安心感**：保存失敗のアラートは消えずに「入力内容はこの画面に残っています」と書いてある。削除は確認シートに対象の要約、削除後6秒の［取り消す］。アプリを閉じても入力途中の内容が戻る（30分以内は入力画面がそのまま開く）
- **振り返りの絞り込み**：シートで条件を選ぶたびに「4件を表示」と件数が変わり、0件の組み合わせを試さずに済む。口座・期間・勝敗が上にまとまっていて、「本番・今月・負け」が6タップ
- **見た目が iPhone の標準アプリに馴染んでいる**：グラデーション・絵文字・すりガラスがなく、設定画面は iOS の「設定」とほぼ同じ形。ダークモードも真っ黒の背景で夜に眩しくない。全画面の文字のコントラストが 4.5:1 以上
- **オフライン**：通信を切っても起動・記録・閲覧ができた。ホーム画面への追加の説明画面は「Safari とホーム画面のアプリでは記録が別々に保存されます」まで書いてあり、つまずきやすい点を先回りしている
- **助言をしない**：損益や RR に「良い」「悪い」の評価や励ましの文がなく、事実だけが並ぶ
